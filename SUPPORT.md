# Support

Plass is maintained on a best-effort basis. The supported product is the
latest version at <https://plass.tayweid.io/> and the latest commit on `main`;
older releases, forks, and locally modified builds are outside the support
scope.

For a reproducible bug or feature proposal, open a GitHub issue and use the
appropriate template. Include your browser and operating system, clear steps,
and the smallest sanitized example needed to reproduce the behavior. Do not
upload a private document merely to demonstrate a problem.

Public issues are not a security channel. Report suspected vulnerabilities
privately as described in [`SECURITY.md`](./SECURITY.md).

There is no guaranteed response time, compatibility commitment, or individual
document-recovery service. Back up important work and keep the original source
files until an export has been checked.
